# Bible Reader content — GRC-Greek

This repository contains the Bible Reader SD-card content for **GRC-Greek**.

## Directory layout

- `text/GRC-Greek/` — all Bible translations and their original nested folder structure.
- `audio/GRC-Greek/` — audio Bible book folders and chapter MP3s.
- `gospel/GRC-Greek/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
